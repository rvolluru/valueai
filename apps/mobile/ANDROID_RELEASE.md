# Android preview and release

Package: `com.jouft.app`. Expo SDK 54 targets Android API 36. Android native sources are generated by EAS; the existing iOS native project is unchanged in identity.

## Build for testing

Run `eas build --platform android --profile preview`. This produces a signed APK for installation on an Android device. Preview currently connects to the production API and the existing Clerk test instance. Use dedicated test accounts; do not send trades to real users or make live payments during QA.

## Device QA

- Login, logout, signup, email verification, and browser deep-link return.
- Camera permission granted/denied, multiple captures, cancel/discard, and app background/foreground.
- Gallery selection, crop/rotate, upload, edit persistence, and fresh analysis.
- Carousel opens the tapped photo; swiping and arrows move one photo at a time.
- Closet Edit/Share/More actions; dropdown dismissal and delete confirmation.
- Android hardware Back, keyboard, edge-to-edge safe areas, and unsaved-form confirmation.
- Marketplace preferences, trade selection, shipping, notification history, and address entry.
- Payment setup and Google Pay in an appropriate test environment.

## Remaining store-release requirements

- Approve the final package ID and supply production launcher/adaptive icon artwork; current icon artwork is not release-ready.
- Configure Firebase Android app with this package ID, supply `google-services.json`, set `android.googleServicesFile`, and upload FCM v1 credentials to EAS. Verify push on a physical device.
- Validate Clerk Android redirect behavior and OAuth signing fingerprints; configure the intended production Clerk instance before a public release.
- Create/configure the Play Console app, signing, tester access, listing screenshots, privacy policy, Data Safety, and account-deletion disclosures.
- Review subscription payment flow against Google Play billing policy before enabling membership purchases in the store build.
- Configure Google Play submission credentials and a testing track. Production EAS builds generate AABs; the APK preview is not a Play Store release.
- Review dependency audit findings before public release. Do not run a forced bulk dependency upgrade without regression testing.
